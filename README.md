## Quick start

1. [Choose a topic](#browse-by-topic) and open its verified feeds.
2. Save that topic’s OPML file and import it into your feed reader, or [import 7,895 subscriptions](https://raw.githubusercontent.com/powerpuff-kitty/feeds.nws.broker/main/directory/opml/all.opml) from the combined file.
3. Use the [CSV](directory/feeds.csv) to filter by language, country, publisher, or feed status.

## Feed status

- **Verified**. The broker successfully parsed the feed at the recorded check.
- **Advertised**. A source or directory advertised the endpoint. Verification is pending.
- **Needs review**. The record needs follow-up, for example on access, format, or parsing.
- **Unavailable**. The endpoint was unavailable at the recorded check.

These are catalogue observations at the recorded check date. The CSV also records listing, access, admission, and rights status. Each record appears under its primary topic. The CSV includes secondary topics.

The OPML files contain original publisher URLs from the broker’s public subscription export. The combined file groups them by topic and includes each exact URL once. Use GitHub’s **Raw** button to save a file and import it into your reader. JSON Feed support depends on the reader.

See [data fields, source, and refresh instructions](MAINTENANCE.md).
